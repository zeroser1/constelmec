CONSTELMEC Backup

Herramienta privada de respaldo para la aplicación de mantenimiento de portones industriales de CONSTELMEC.

¿Para qué sirve?

Genera copias de seguridad de la base de datos y los archivos operativos de CONSTELMEC. Las copias se cifran antes de almacenarse en una cuenta de Google Drive autorizada por su administrador.

La integración con Google Drive se utiliza exclusivamente para guardar y comprobar archivos de respaldo. No es un servicio público ni permite a visitantes consultar datos operativos.
